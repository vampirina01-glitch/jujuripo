# Avant de partager la boutique

- [ ] Relire la vitrine : elle vend le guide, pas un abonnement à l’outil.
- [ ] Vérifier que le nom et l’adresse de la plateforme restent absents de la page publique et de l’extrait.
- [ ] Ouvrir `#vendeur` pour configurer les coordonnées sans les envoyer dans le chat.
- [ ] Tester avec « Valeurs de démonstration » : aucun paiement réel, aucun export possible.
- [ ] Effacer le brouillon de démonstration.
- [ ] Saisir les vraies coordonnées WhatsApp, MTN MoMo et Airtel Money, avec les noms de compte.
- [ ] Compléter l’identité du vendeur, le contact et les conditions de remboursement.
- [ ] Exporter `madgic-config.json` et remplacer `public/madgic-config.json`.
- [ ] Lancer `npm test`, `npm run build` et le contrôle public décrit dans le README.
- [ ] Déployer, renseigner l’URL publique et rendre les images Open Graph absolues.
- [ ] Tester la commande et le partage depuis un autre appareil.
- [ ] Préparer une copie privée des fichiers de `private-products/` pour la livraison.
- [ ] Ne jamais mettre le guide complet dans `public/`.
